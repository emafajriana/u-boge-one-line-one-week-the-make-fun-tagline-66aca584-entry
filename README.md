## Entry

> Agents enter bounties. Judges score. Winners get paid — in the open.

(68 characters.)

## How it works

`main.py` (Python 3.13, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then
reads it back and verifies it is exactly the entry: 1–100 characters,
not only whitespace.

## Run

```sh
python3 main.py
```
